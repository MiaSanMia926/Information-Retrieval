# 检索评估

在图片与索引准备好后，从仓库根目录运行：

```bash
python scripts/evaluate.py
```

## 指标口径

`GROUND_TRUTH` 在脚本中按查询列出相关图片文件名。测试数据必须包含这些图片；自行更换图库时，应同步维护相关性标注。

| 输出 | 计算方式 |
| --- | --- |
| P@5 | 前 5 项中相关图片数 / 5 |
| R@5 | 前 5 项中相关图片数 / 该查询全部标注相关图片数 |
| MRR | 实际为 MRR@5：前 5 项内第一张相关图片排名的倒数，无命中为 0 |

脚本报告各查询的平均值，并比较纯 CLIP、BM25 权重 0.3 和权重 0.15 三种设置。

## 与在线页面的区别

脚本使用 CLIP 召回排名的倒数得分，并对 BM25 分数归一化；页面直接叠加 CLIP 内积分数与原始 BM25 分数。脚本 BM25 优先读取 caption，页面只读取文件名。脚本不使用页面的三提示词扩展，也没有真实交互反馈实验。

因此，这只是现有离线基线，不是严格对应页面的消融实验。比较算法时还应固定图片集、模型版本、相关性标注与检索设置。原始图片未随仓库发布，本文不填写未经复现的指标。
